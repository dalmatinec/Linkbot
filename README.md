# Linkbot: реклама через гостевого бота

Бот не состоит в группах и не занимает в них слот. Юзербот (Telethon) сидит в группах и по расписанию
упоминает бота, бот в гостевом режиме (Bot API 10) публикует рекламный пост. Всё управляется из админки в боте.
Один процесс: бот + юзербот + планировщик, база SQLite.

Старая версия Linkbot лежит в ветке `old-linkbot`.

## Что умеет (/admin)

| Раздел | Что можно |
|---|---|
| 📝 Посты | переслать пост (медиа, форматирование, премиум-эмодзи и URL-кнопки сохраняются) или создать: текст, фото, видео, GIF, файл; сменить текст или медиа, название, копия, предпросмотр |
| 🔘 Кнопки | добавить пачкой (`Текст - ссылка`, ряд через `\|`), раскладка как в посте; у каждой кнопки текст, ссылка, цвет, премиум-иконка (первое премиум-эмодзи в тексте), ⬆️⬇️⬅️➡️ перемещение по рядам |
| 📣 Рассылки | посты по кругу + группы + интервал (пресеты или своё), запуск/пауза, круг сейчас, отчёт по кругу |
| 👥 Группы | список чатов юзербота, обновление, ручная пауза, сброс ошибок, статистика по группе |
| ⚙️ Настройки | задержка между группами (2 сек) + случайная добавка, антифлуд на группу, лимит в сутки, автопауза после N ошибок, тихие часы, удаление сообщения-вызова, отчёты |
| 📊 Статус | юзербот, посты и ошибки за сутки, ближайшие круги |

Защита: юзербот тегает группы строго по очереди с задержкой, разные рассылки не перемешиваются;
FloodWait и медленный режим обрабатываются; если бот не ответил, голый «@бот» удаляется;
бот отвечает только вашему юзерботу и только когда ждёт пост для этой группы.

Ограничения Telegram: гостевой бот публикует копию поста (не пересылку с плашкой), альбомы не поддерживаются,
в группах с «Запретить копирование» гостевые боты не работают.

## Установка
```bash
git clone https://github.com/dalmatinec/Linkbot /opt/linkbot && cd /opt/linkbot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env              # BOT_TOKEN, OWNER_IDS, API_ID, API_HASH
.venv/bin/python -m app login     # вход юзербота: номер, код, 2FA
cp deploy/linkbot.service /etc/systemd/system/ && systemctl enable --now linkbot
journalctl -u linkbot -f
```
В @BotFather у бота включить **Guest Mode**. Данные и сессия юзербота лежат в `data/` (в git не попадают).
