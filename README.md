# Linkbot: реклама через гостевого бота

Схема: юзербот раз в час пишет `@ваш_бот` в согласованных группах → бот (не состоя в группе) публикует рекламный пост с кнопками. Посты идут по кругу. Слот бота в группе не занимается.

Старая версия Linkbot лежит в ветке `old-linkbot`.

## Установка
```bash
git clone https://github.com/dalmatinec/Linkbot && cd Linkbot
pip install -r requirements.txt
cp .env.example .env    # вписать токены
```
aiogram нужен свежий, с поддержкой Bot API 10.0 (guest mode).

## Настройка
1. **@BotFather** → ваш бот → Bot Settings → включить **Guest Mode**.
2. **my.telegram.org** → API development tools → `API_ID` и `API_HASH` для юзербот-аккаунта.
3. `.env`: токен, username бота, id юзербота в `ALLOWED_CALLERS`, `API_ID`, `API_HASH`.
   id аккаунта юзербот пишет в лог при первом запуске.
4. `config.py`: рекламные посты (`POSTS`), группы (`CHATS`), интервал.

## Запуск
Два процесса (на сервере через screen/tmux или systemd):
```bash
python guest_bot.py
python userbot.py      # первый раз спросит номер и код из Telegram
```

## Важно
- Репозиторий публичный: токены только в `.env`, он в `.gitignore`. Файл `userbot.session` тоже не коммитить, это вход в аккаунт.
- В группе должна быть **выключена защита контента** («Запретить копирование»), иначе гостевые боты не работают.
- Бот отвечает только на вызовы от `ALLOWED_CALLERS`, чужие упоминания игнорирует.
- Добавляйте только группы, где админы согласны, и не ставьте интервал слишком частым: за массовые однотипные сообщения Telegram замораживает аккаунты.
- `DELETE_TRIGGER = True` удаляет сообщение «@бот» после ответа. Сначала проверьте на одной группе, что пост бота при этом остаётся.
